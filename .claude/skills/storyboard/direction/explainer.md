# Direction — Explainer

Goal on screen: **make one idea click**. Clear, calm, structured; the screen teaches.

| | |
|-|-|
| Scene length | 3–5 s; hold diagrams long enough to read |
| Cuts | On concept boundaries, not on every sentence |
| Transitions | Smooth (12–15 frames): `fade`, `slide` in reading direction; avoid `pushCut` |
| Screen density | Labels and diagrams over sentences; build up step by step |
| Motion | Smooth; elements enter in the order the VO mentions them |
| Music | Light, curious, low in the mix |
| SFX density | Low: soft ticks on new labels/steps, nothing on every word |

## Beat → scene patterns

| Beat | Typical scenes | Notes |
|------|----------------|-------|
| Hook | TextCard (question/myth) · NumberSlam (surprising fact) | Question text on screen as it's asked |
| Context | TextCard with `kicker` | Set where the viewer meets this |
| Core steps | ListCards `marker: number` · one TextCard per step | Numbers on screen match "first/then/finally" in VO |
| Example | NameCards / StatCounter / TextCard | Concrete case; show the real number or name |
| Takeaway | TextCard with `emphasis` on the key term | The sentence the viewer should remember |
| CTA | EndCard (`showLogo` if branded) | Soft: follow / next part |

## Avoid

- More than one new element per second
- Decorative motion that competes with the explanation
- Switching styles or surfaces randomly — keep one light surface for teaching, dark only for hook/takeaway
