# Direction — Social short

Goal on screen: **no reason to swipe away**. Fast, bold, readable on mute.

| | |
|-|-|
| Scene length | 1–2 s; something changes on screen at least every 1.5 s |
| Cuts | On every point/punchline; jump-cut energy |
| Transitions | Very fast (6–8 frames): `pushCut`, `slide`, hard cuts (`none`) |
| Screen density | 2–5 big words per card; numbers as "#3" |
| Motion | Bouncy or snappy; pops and slams |
| Music | Trend-style, punchy; beat-synced cuts |
| SFX density | Medium: a sound on the key changes only (not every cut), riser before the payoff |

## Beat → scene patterns

| Beat | Typical scenes | Notes |
|------|----------------|-------|
| Hook | TextCard (big, `emphasis`) · NumberSlam | Must work muted; text visible on frame 1 |
| Payload items | One TextCard or NumberSlam per item (`kicker: "#1"`) | Strongest item last |
| Payoff | NumberSlam / TextCard on a contrasting surface | Longest hold in the video (still ≤ 3 s) |
| Loop / CTA | TextCard (comment prompt) or EndCard without logo | Last frame should flow back into the first |

## Avoid

- Fades (too soft for this format)
- Any scene > 3 s
- Small text: nothing under ~56 px at 1080 wide
