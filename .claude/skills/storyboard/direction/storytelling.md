# Direction — Storytelling / documentary

Goal on screen: **immersion and tension**. Cinematic, restrained, let moments breathe.

| | |
|-|-|
| Scene length | 3–6 s; slow holds on reveals, quicker cuts in rising tension |
| Cuts | On dramatic turns; cut faster as tension rises, slower after the climax |
| Transitions | `fade` (15–20 frames) for time jumps; hard cut (`none`) for shocks |
| Screen density | Minimal text: date/place stamps, names with roles, one key number |
| Motion | Smooth and slow; avoid bouncy |
| Music | Atmospheric, builds with the story; silence (or a single hit) on the reveal |
| SFX density | Low but meaningful: ambience, one impact at the turn |

## Beat → scene patterns

| Beat | Typical scenes | Notes |
|------|----------------|-------|
| Hook | TextCard (dramatic line) · NumberSlam (date/number) | Start mid-tension, dark surface |
| World / character | NameCards · TextCard with `kicker` = "Mumbai, 1993" | Establish who/where/when |
| Rising tension | Sequence of short TextCards | Shorten each successive scene |
| Climax / turn | TextCard on a contrasting surface, longer hold | Pair with `[SILENCE]` in the VO |
| Resolution | StatCounter / TextCard | What happened after |
| CTA | EndCard, minimal | Often logo + "follow for part 2" |

Photo/footage-led documentary needs the **Documentary** style (needs build) — ask before using.

## Avoid

- Bright, playful styles (pop art, neobrutalism) for serious subjects
- Busy backdrops behind sensitive content
