# Playbook — Social short

For fast, trend-style Reels / Shorts / TikToks: listicles, hot takes, quick facts,
"things you didn't know", relatable content, reactions. The viewer should **watch to
the end, rewatch, and share or comment**.

## Defaults

| | |
|-|-|
| Length | 15–35 s — default 25 s |
| Hook window | first 1.5 s (≤ 5 spoken words) — on-screen text must hook even on mute |
| Pace | 3.0 wps — fast, punchy, zero filler |
| Tone | casual, bold, personality-driven; talk like a creator, not a brand |
| Point of view | "you" / "I" |

## Hook formulas

1. **Numbered list** — "3 apps that feel illegal to know."
2. **Hot take** — a confident, defensible opinion. "Unpopular opinion: to-do lists make you slower."
3. **"POV" / relatable** — a situation the audience instantly recognises.
   "POV: you said 'five more minutes' an hour ago."
4. **Stop-scroll command** — "Stop scrolling if you're learning to code."
5. **Withheld answer** — "Wait for number three."  / "The last one changed my life."
6. **Challenge / test** — "Only 1 in 10 people get this right."

Hooks must work **muted**: the ON-SCREEN line alone must be enough to stop the scroll.
Don't promise what the video doesn't deliver ("the last one" must be the strongest).

## Structure

Draft the spoken piece before dividing it into beats. These shares are guides.
Independent items and numbering are appropriate for an explicitly requested
listicle; a product ad should still have a connected argument rather than inherit
a list format merely because it is short.

| Beat | Share of time | Job |
|------|---------------|-----|
| Hook | ~8% | Stop the scroll, on sound and on mute |
| Payload | ~75% | List items / points, each 3–6 s, strongest last |
| Payoff / twist | ~10% | The best item, punchline or reveal |
| Loop / CTA | ~7% | Line that loops back to the start, or a comment prompt |

## Writing rules

- **Cut every word that isn't needed.** No intros, no "hey guys", no "so today".
- **A new point or ON-SCREEN text change every 1–2 s.**
- **Strongest item last**, second-strongest first.
- **Loop it:** the last line can flow into the first ("…which is why…") for rewatches.
- **Comment bait that's genuine:** ask a real question the audience will want to answer.
- ON-SCREEN text: big, 2–5 words, changes with each point; numbers as digits ("#3").

## CTA patterns

- "Which one did you know? Comment."
- "Follow for part two."
- "Send this to someone who needs it."

## Avoid

- Hooks longer than 1.5 s
- More than 5 list items in 30 s
- Facts that can't be verified — viral shorts get fact-checked in the comments
- Clickbait that the payoff doesn't honour
